# Eryndex 企業形象官網改版紀錄

日期：2026-09-18

## 改版目標

本次改版將網站由產品操作展示頁，調整為可供客戶、合作夥伴與外部機構查核的企業形象官網。網站的首要任務是清楚說明 Eryndex 智序科技的定位、業務範圍、產品系統與正式聯絡方式，而不是在網站內完成試用或購買。

## 敘事結構

1. 以企業使命與工作方法建立第一印象。
2. 說明企業工作分散、資訊失序與權限缺乏脈絡的真實問題。
3. 將 Space、Files、Shield 整合為同一套企業運作系統，分別承擔工作協作、資訊管理與存取治理責任。
4. 交代設計原則與可提供的服務範圍。
5. 提供公司資訊、服務地區、聯絡信箱、隱私權與使用條款入口。

## 設計原則

- 使用一致的淺色企業視覺與連續故事線，降低區塊拼貼感。
- 保留既有品牌識別與三組 3D 產品視覺，但不再放入互動式產品操作視窗。
- 以大標題、留白、編輯式排版與少量深色敘事段落建立正式科技公司形象。
- 桌面、平板與手機皆維持相同資訊順序與閱讀邏輯。
- 未提供的公司登記資料、地址、電話與法律資訊不自行杜撰。

## 驗證範圍

- Astro 型別與內容檢查
- 正式靜態建置
- 內部連結與素材引用檢查
- 繁中、簡中與英文在地化檢查
- 桌面與手機版面檢查
- 主要區塊唯一性與橫向溢出檢查
