# Eryndex Design System Direction

## Overall tone
Premium, calm, warm, precise, modern, reliable, editorial, and human.

## Base palette
- Warm Ivory / Off White background
- Soft neutral grays
- Deep warm charcoal typography

## Product accents
- Space: Soft Coral
- Files: Pale Cyan
- Shield: Pale Mint
- Services: Pale Lavender

Accent colors are identifiers, not full-section fills.

## Visual language
Use:
- Large negative space
- Editorial typography
- Frosted translucent materials
- Paper-like diffusion
- Soft glass
- Warm natural light
- Restrained geometry
- Calm micro-interactions

Avoid:
- Dark navy SaaS themes
- Neon gradients
- Cyberpunk
- AI brain / AI robot imagery
- Particle-network backgrounds
- Dashboard everywhere
- Feature-card grids everywhere
- Holograms
- Generic Bootstrap SaaS layouts

## Typography
Typography is a primary visual element. Use large, confident editorial headings, comfortable body copy, generous line-height, and strong hierarchy. Mobile typography should be re-composed rather than merely scaled down.

## Layout
Favor asymmetry, large spacing, controlled editorial rhythm, and product storytelling over repetitive equal-sized cards.

## Motion
Motion should be slow, precise, calm, and purposeful. Use subtle reveal, depth, restrained parallax, hover response, and section transitions. Avoid bouncing, spinning, excessive fly-ins, particle effects, scroll hijacking, and gimmicky cursor effects. Respect `prefers-reduced-motion`.

## UI mockups
Product UI should be built as actual frontend components with readable text. Space, Files, and Shield must share design DNA but be immediately distinguishable by information architecture and function, not merely by color.

## Responsive
Design explicitly for desktop, laptop, tablet, and mobile. Do not treat responsive behavior as simple shrink-to-fit.

## Accessibility
Use semantic HTML, keyboard navigation, visible focus states, sufficient contrast, alt text, accessible forms, ARIA only where needed, and reduced-motion support.
