# Eryndex Files

## Positioning
Enterprise File Platform.

## Core question
How the company manages and preserves information.

## Purpose
Provide a complete enterprise file-management layer for storing, synchronizing, sharing, versioning, protecting, backing up and restoring business information.

## Core capabilities
- Enterprise file organization
- Synchronization
- Controlled sharing
- Version history
- Permissions
- Backup and restore
- Information lifecycle management

## Boundaries
Files is not merely generic cloud storage. It owns enterprise information preservation and file operations. It may integrate with Space for work context and Shield for identity/access controls.

## Visual concept
Layers.

## Accent
Pale Cyan.

## Representative UI direction
File Browser / Sharing / Versions / Backup / Restore. The interface must be clearly different from Space and Shield.
