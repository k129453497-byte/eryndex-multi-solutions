# Eryndex Services

## Positioning
Professional Services Layer supporting Eryndex Space, Files and Shield.

## Core principle
Products solve everyday business problems. Services solve how those products are introduced, configured, adapted and supported inside a real company.

## Services scope
- Implementation
- Migration
- Configuration
- Training
- Technical Support
- Maintenance
- Customization
- System Integration

## Presentation model
Do not present these as eight separate software products. Organize Services as three stages:

### 1. 導入你的環境
- Product deployment
- Initial environment setup
- Account and organization setup
- Data migration
- Access and security configuration

### 2. 配合你的工作方式
- Workflow configuration
- Automation
- System integration
- Customization
- Training

### 3. 持續陪企業運作
- Technical support
- Troubleshooting
- Configuration adjustment
- Maintenance
- Continuous optimization

## Boundaries
Do not create an `Eryndex Support` software product. Product-native capabilities remain inside their products. Example: Files version restore is a Files feature; helping a customer migrate NAS data or design a retention policy is a Service.

## Message
讓產品真正適合你的企業。

Suggested homepage line:
「軟體只是開始，我們陪你真正落地。」

## Visual direction
Human / Service layer.
Accent: restrained Pale Lavender.
Use typography, process layout, restrained geometry, subtle motion, and optional natural SMB-oriented photography rather than a fourth abstract product master.
