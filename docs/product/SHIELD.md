# Eryndex Shield

## Positioning
Enterprise Security Platform.

## Core question
How the company controls trust and access.

## Purpose
Provide a clear, manageable security layer for identity, devices, access, permissions, policies, risk visibility and auditability.

## Core capabilities
- Identity and authentication
- MFA
- Device awareness
- Access control
- Permissions and security policy
- Risk visibility
- Audit records
- Basic security events

## Boundaries
Shield is not an antivirus product and should not be presented with hacker/cyberpunk imagery. It owns trust, access and security control. It may integrate with Space and Files without becoming a dependency for either.

## Message
讓每一次存取建立在正確的信任上。

## Visual concept
Boundary.

## Accent
Soft Mint / Pale Cyan-Green.

## Representative UI direction
Identity / Devices / Access / Security / Audit. The interface must communicate a security-control product rather than a recolored generic dashboard.
