# Eryndex Space

## Positioning
Enterprise Work Platform.

## Core question
How the company works.

## Purpose
Help teams organize work, collaboration, projects, knowledge, documents and repeatable workflows in one coherent workspace.

## Core capabilities
- Workspaces and team collaboration
- Projects and tasks
- Knowledge and documentation
- Internal workflow coordination
- Lightweight automation
- Shared context across teams

## Boundaries
Space is not the enterprise file system and is not the security platform. It may integrate with Files and Shield, but it must deliver standalone value.

## Message
讓工作形成秩序。

## Visual concept
Structure.

## Accent
Soft Coral.

## Representative UI direction
Workspace / Projects / Tasks / Knowledge. Avoid making the UI look like Files or Shield with only a color change.
